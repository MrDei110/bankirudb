# Архив банковских отзывов

Учебный проект по базам данных: PostgreSQL хранит отзывы о банках и их лингвистическую разметку, а веб-интерфейс позволяет искать по тексту и по начальной форме слова. Например, поиск по лемме «комиссия» находит и «комиссии», и «комиссию» и показывает предложения с совпадениями.

Исходный учебный корпус содержит **36 банков, 1 994 отзыва, 15 823 предложения, 7 531 лемму и 283 677 токенов**. В репозитории вместо корпуса — шесть вымышленных отзывов для демонстрации.

По реальному корпусу опубликована [подробная статистика](docs/corpus-statistics.md): оценки, тональность, объём по банкам и месяцам, длина текстов, разметка и выбранные банковские леммы. Исходные тексты и записи отдельных отзывов остаются локальными.

## Быстрый запуск демо

Понадобится запущенный Docker Desktop или Docker с Compose. В корне проекта выполните:

```powershell
docker compose -p bankiru-demo -f compose.demo.yaml up -d --build --wait
```

Откройте [http://localhost:5002/](http://localhost:5002/), введите `комиссия`, выберите «По лемме» и откройте любой из трёх результатов. Для демо не нужны `.env`, CSV и MyStem. У демо своя база и том, отдельные от учебной БД.

Остановить демо: `docker compose -p bankiru-demo -f compose.demo.yaml down`.

## Запуск с локальным корпусом в Windows

| Что нужно | Что запустить из корня проекта |
|---|---|
| База и DBeaver | `start_database.cmd` |
| База и веб-интерфейс | `start_interface.cmd`, затем открыть [локальную страницу](http://localhost:5001/) |

Запускатели ждут готовности Docker Desktop и PostgreSQL. Для первого запуска веб-интерфейса нужен интернет, чтобы собрать образ. Если запуск остановился, подробности будут в `.local/start.log`.

Сохранённое подключение DBeaver: `localhost:15432`, база `bankiru`, пользователь `bankiru_user`. Локальный пароль и порты задаются в `.env`. Если файла нет, скопируйте `.env.example` в `.env` и заполните пароль. Для существующей базы укажите её прежний пароль: изменение `.env` не меняет пароль внутри PostgreSQL. В уже настроенной локальной папке `.env` подготовлен.

Данные PostgreSQL хранятся в томе `bankiru-study_bankiru_data`. Переезд папки не меняет имя этого тома. Первый запуск из нового места может пересоздать контейнер из-за нового пути к SQL-схеме; повторно загружать данные в имеющийся том не нужно. Чтобы остановиться после работы, используйте **Stop** в Docker Desktop. Удаление тома удалит содержимое базы.

## Где что лежит

| Папка | Содержимое |
|---|---|
| `database/schema/` | SQL-схема PostgreSQL; редактируемая модель Toad Data Modeler в локальной копии |
| `database/import/` | Загрузка банков и отзывов из CSV; загрузка предложений, токенов и лемм из JSONL |
| `database/queries/` | Учебные SQL-запросы для DBeaver: `INSERT`, `SELECT`, `JOIN` и дополнительные примеры |
| `nlp/` | Подготовка разметки через MyStem и Razdel; ранний вариант с Natasha — в `nlp/experiments/` |
| `web/` | Веб-интерфейс: Flask, HTML-шаблоны и стили |
| `demo/` | SQL для заполнения отдельной демонстрационной БД вымышленными данными |
| `infra/`, `scripts/` | Дополнительный файл Compose для веб-сервиса и запускатель Windows |
| `data/` | Исходные отзывы, готовая разметка и результаты пробных запусков; локальные файлы |
| `docs/` | [Архитектура](docs/architecture.md) и [описание схемы](docs/database-schema.md) |

## Как показать проект

1. Запустите `start_database.cmd`. В DBeaver откройте подключение `bankiru` и проверьте количество строк запросом из `database/queries/existing_queries.sql`.
2. Для `JOIN` и других учебных команд откройте файлы `join_queries.sql` и `additional_queries.sql`. Выполняйте по одному запросу. `INSERT` в `existing_queries.sql` — выдержки для объяснения загрузки, они оставлены в комментарии.
3. Запустите `start_interface.cmd`. В браузере введите `комиссия`, выберите режим «По лемме» и откройте один из отзывов, чтобы показать найденные предложения.

## Где хранить оригинальные отзывы

Файлы кладите **в локальную папку проекта**. Пути ниже указаны от её корня; если папок `raw` и `processed` ещё нет, создайте их внутри `data`.

| Куда положить | Что это |
|---|---|
| `data/raw/bankiru_fulltext.csv` | **Обязательный исходный файл.** Оригинальная учебная выборка: 2 000 строк, после удаления дублей — 1 994 отзыва. Его читает `database/import/import_reviews.py`. |
| `data/processed/mystem_annotation_review.jsonl` | **Готовая разметка именно этого CSV.** Её читает `database/import/import_annotation.py` для загрузки предложений, токенов и лемм. Если файла нет, его можно заново получить из исходного CSV через `python nlp/lemmatize_mystem.py --mode review` (инструкция ниже). |

Большой корпус на 180 000 отзывов, файлы `mystem_preview*.csv` и пробные выборки для восстановления этой БД не нужны. Оригиналы и разметка остаются локальными: `.gitignore` исключает их из Git. Для вымышленного демо на порту `5002` эти файлы не нужны.

## Как восстановить данные на другой машине

Эти команды нужны **только для новой или пустой базы**, а также для проверки входных файлов. Выполняйте их из корня проекта в PowerShell. Для существующей локальной БД достаточно запускателя.

```powershell
docker compose up -d --wait postgres
python database/import/import_reviews.py --check-only
python database/import/import_annotation.py --check-only
python database/import/import_reviews.py
python database/import/import_annotation.py
```

Загрузчики используют Docker CLI и не требуют сторонних библиотек Python. Схема применяется при первой инициализации пустого тома.

Чтобы заново подготовить разметку, установите зависимости и запустите:

```powershell
python -m pip install -r nlp/requirements.txt
python nlp/lemmatize_mystem.py --limit 10
python nlp/lemmatize_mystem.py --mode review
```

Первый запуск MyStem может потребовать загрузки анализатора. Пробный запуск пишет в `data/experiments/`, полный — в `data/processed/`. Если у вас уже есть готовый JSONL для этого же CSV, пересчитывать разметку не нужно.

## Данные и настройки в Git

В репозиторий входят исходный код, SQL-схема, документация, учебные запросы и вымышленные данные. `.gitignore` исключает `.env`, реальные отзывы и их разметку, журналы, резервные копии и локальную модель Toad с путями на компьютере автора. Если нужен скриншот для портфолио, снимайте интерфейс в режиме демо на порту `5002`.
