# Локальные данные

- `raw/bankiru_fulltext.csv` — исходные 2 000 строк; загрузчик оставляет 1 994 уникальных отзыва.
- `processed/mystem_annotation_review.jsonl` — полная разметка для загрузки в БД.
- `processed/mystem_preview_review.csv` — табличное представление той же разметки для просмотра.
- `experiments/` — результаты пробных прогонов и диагностика MyStem.

Кроме этой памятки, файлы в `data/` исключены из Git. Если в новой копии проекта их нет, добавьте собственные исходные данные в `raw/`, затем подготовьте разметку или перенесите свой JSONL в `processed/`. Имена файлов и порядок запуска приведены в главном `README.md`.
