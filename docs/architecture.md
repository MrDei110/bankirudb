# Архитектура «Архива банковских отзывов»

Учебное задание по БД к 10.11. Цель интерфейса — найти отзывы о банках, открыть полный текст и увидеть предложения, в которых встречается заданная лемма.

## Компоненты

| Компонент | Ответственность |
|---|---|
| Браузер | Показывает форму поиска и фильтры, список отзывов и страницу отдельного отзыва. |
| Flask + HTML-шаблоны | Принимает параметры формы, выполняет запросы к БД и формирует страницу с результатом. |
| PostgreSQL | Хранит банки, отзывы и готовую лингвистическую разметку; выполняет фильтрацию и соединения таблиц. |
| Docker Compose | Запускает веб-сервис и PostgreSQL в одной сети. Данные PostgreSQL сохраняются в уже существующем томе проекта `bankiru-study`. |

Браузер обращается к Flask по адресу `http://localhost:5001`. Flask соединяется с сервисом `postgres` внутри Docker. Браузер не подключается к базе напрямую. DBeaver по-прежнему можно использовать отдельно, для показа таблиц и SQL-запросов.

## Как проходит поиск

1. Пользователь вводит запрос и при желании выбирает банк и оценку.
2. В режиме «По тексту» Flask ищет введённую строку в заголовке и тексте отзыва. В режиме «По лемме» он ищет точную начальную форму в `lemmas`.
3. Для поиска леммы БД проходит по связям `lemmas → tokens → sentences → reviews`. Проверка `EXISTS` возвращает каждый отзыв один раз, даже если слово встретилось несколько раз. Таблица `banks` добавляет название банка.
4. Flask возвращает список результатов. При открытии отзыва после поиска по лемме показываются найденные предложения и полный текст.

Пример для демонстрации: ввести **комиссия**, выбрать **«По лемме»**, открыть результат. В совпавшем предложении может быть форма «комиссии» или «комиссию», потому что поиск идёт по сохранённой лемме.

## Связь с выданным архивом

За основу взят подход из `TomitaSite.zip`: HTML-форма отправляет данные во Flask, сервер обрабатывает запрос и выводит результат в шаблоне. В выданном примере сервер запускает Томита-парсер для футбольных текстов. В нашей реализации сервер обращается к PostgreSQL, где разметка банковских отзывов уже загружена. Отдельное требование интегрировать Томита-парсер не подтверждено, поэтому в текущий вариант он не входит.

## Запуск и показ

1. Запустить Docker Desktop и дождаться готовности движка.
2. Дважды щёлкнуть `start_interface.cmd` в корне проекта. При первой сборке веб-образа Docker скачает образ Python и установит зависимости приложения; нужен интернет.
3. Откроется `http://localhost:5001/`. Если браузер не открылся, ввести адрес вручную.
4. Показать поиск по тексту, затем поиск по лемме и переход к найденным предложениям. При желании показать те же таблицы в DBeaver.

Скрипт добавляет только веб-сервис к уже существующему проекту Compose. Интерфейс читает данные через `SELECT` в транзакциях только для чтения. Схему БД менять и повторно запускать импорт не требуется.
