## Воспроизводимость

Локальные источники — исходный CSV и разметка MyStem + Razdel. Генератор удаляет полные дубли по ссылке и сверяет каждый текст разметки с исходником. Опубликованы только агрегаты. Публичная сводка не включает редкие фразы, даты отдельных отзывов и разбивки «банк × дата × оценка».

```powershell
python scripts/generate_corpus_statistics.py
```

Те же агрегаты доступны в [JSON](corpus-statistics.json). Для пересчёта нужны локальные файлы из README.
